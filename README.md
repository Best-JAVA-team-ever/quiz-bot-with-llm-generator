# Quiz Bot with LLM Question Generator

Интеллектуальный Telegram-бот для обучения и проведения викторин с использованием ИИ (GigaChat).

## Основные возможности
- **Викторины**: адаптивный подбор вопросов на основе вашего прогресса и сложности.
- **ИИ-Генерация**: автоматическое создание вопросов, пояснений и подсказок через GigaChat.
- **Группы**: возможность соревноваться с друзьями, вступать в группы по ссылкам и смотреть общую статистику.
- **Расписание**: автоматическая отправка вопросов пользователям и группам.
- **Админка**: полное управление базой вопросов и тем через Telegram.
- **REST API**: эндпоинты для мониторинга и получения списка пользователей.

## Команды

### Для всех пользователей
- `\help` — список доступных команд.
- `\quiz start [тема]` — начать викторину (можно указать темы через пробел).
- `\score [тема]` — просмотреть свою статистику.
- `\score reset` — сбросить свой прогресс.
- `\group leave` — выйти из группы.
- `\group score` — статистика по вашим группам.

### Для администраторов
- `\add tag <название>` — добавить новую тему.
- `\add question <тема1> <тема2>...` — добавить вопрос вручную (пошаговый диалог).
- `\add question gen <тема1>...` — сгенерировать вопрос через ИИ.
- `\get questions [all|<тема>]` — просмотр базы вопросов.
- `\update question <ID>` — пошаговое обновление вопроса.
- `\delete question <ID|Тема|all>` — удаление вопросов.
- `\schedule set <cron>` — настройка автоматической рассылки (например, `0 0 12 * * *`).
- `\schedule off` — отключение рассылки.
- `\upgrade <ID>` — назначить пользователя администратором.
- `\group create <название>` — создать новую группу.

## Развертывание

### Требования
- Docker и Docker Compose
- Токен Telegram бота (@BotFather)
- API ключ GigaChat

### Запуск через Docker Compose
1. Создайте или обновите файл `.env` (или используйте `properties.env`):
   ```env
   TELEGRAM_BOT_TOKEN=ваш_токен
   GIGACHAT_API_KEY=ваш_ключ
   ADMIN_CHAT_IDS=ваш_телеграм_id
   JWT_SECRET=секретный_ключ_для_api
   ```
2. Запустите проект:
   ```bash
   docker-compose up -d
   ```
Приложение будет доступно на порту `8080`.

## REST API
- `GET /healthcheck` — состояние системы.
- `GET /users` — список пользователей (требует заголовок `X-API-KEY`).
